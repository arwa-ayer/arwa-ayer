🚢 Felix Simba en images

Une appli web, expliquée en dessins

Pas de jargon. Juste des images simples pour comprendre comment le code arrive jusqu'à toi — et comment il est fabriqué tout seul.

Le code est rangé dans des boîtes. Un port fait tourner ces boîtes. Une chaîne automatique fabrique et livre les boîtes toutes seules.

3 idées, et tu as tout compris

📦

Une boîte = un conteneur

Tout le code d'une appli est emballé dans une boîte qui marche pareil partout.

⚓

Un port = Kubernetes

Le port fait tourner plein de boîtes, les surveille, et en relance une si elle tombe en panne.

🏭

Une chaîne = le pipeline

Dès que tu changes le code, une chaîne automatique teste, fabrique et livre une nouvelle boîte.

⚙ Comment une nouvelle version arrive

Un peu comme une usine : 4 postes de travail, l'un après l'autre.

✍️

1. Le code

Quelqu'un écrit ou corrige du code.

→
🧪

2. Le contrôle

Des tests vérifient que rien n'est cassé.

→
📦

3. La boîte

Le code est emballé dans une nouvelle boîte.

→
🚀

4. La livraison

La boîte est installée dans le port.

⚠️ Pour les livraisons importantes (en production), un humain doit cliquer sur « OK » avant que ça parte — comme un dernier coup d'œil avant de fermer le camion.

📁 Les fichiers, en un dessin chacun

Chaque fichier du projet a un rôle très simple.

📚

Le dictionnaire

_helpers.tpl

Il donne toujours le même nom et la même adresse à l'application, pour que tout le monde utilise le même mot.

📋

La fiche réglages

values.yaml

Elle dit combien de boîtes lancer, quelle version installer, et quelles adresses utiliser.

👷

Le contremaître

deployment.yaml

Il fait tourner les boîtes, vérifie qu'elles vont bien, et en relance une toute seule si besoin.

🚪

Les panneaux

service.yaml & ingress.yaml

Une porte publique laisse entrer les visiteurs, un panneau interne indique où aller ensuite.

🧠

Le guide

nginx.conf

Il regarde chaque visite et décide : montrer une page, ou transmettre à l'usine back.

💼

Le coffre-fort

Secret Kubernetes

Il garde les mots de passe et les codes secrets, lus par l'usine back sans jamais être écrits en clair.
